# 멜로틴 MELLOTEIN 브랜드 사이트

정적 웹사이트입니다. 별도 빌드 없이 GitHub Pages에 그대로 올리면 됩니다.

## 폴더 구성

```
mellotein-site/
├── index.html        메인페이지 (HOME v2 확정안)
├── brand.html        01 브랜드 · 멜로틴 이야기
├── product.html      02 제품 · 프로틴 치즈케이크
├── assets/
│   ├── images/       사이트 이미지 12개 (webp, png)
│   └── js/site.js    모바일 메뉴, 하단 고정 바, 단백질 숫자 카운트, 블라인드 테스트 결과, 맛 투표
├── .nojekyll         GitHub Pages가 파일을 그대로 쓰도록 하는 빈 파일
└── README.md
```

## GitHub Pages에 올리는 법

1. GitHub에서 새 저장소를 만듭니다 (예: `mellotein-site`).
2. 이 폴더 **안의 파일과 폴더 전체**를 저장소 맨 위에 올립니다. `index.html`이 저장소 최상단에 있어야 합니다.
3. 저장소 Settings → Pages → Branch를 `main` / `/ (root)`로 정하고 저장합니다.
4. 잠시 뒤 `https://<계정명>.github.io/<저장소명>/` 주소로 사이트가 열립니다.

## 오픈 전 교체할 내용

- 블라인드 테스트 수치(56/100명)와 영양정보 중 분석 전 항목은 가안입니다.
- 푸터의 사업자 정보·연락처는 예시값입니다.
- '맛 증명', '운동 후 루틴', '구매·체험' 메뉴는 아직 페이지가 없어 메인으로 연결됩니다.
- 공식몰 버튼, 카카오톡 채널, SNS 링크는 실제 주소로 바꿔야 합니다.
- 브랜드 필름 영상은 비공개 구글 드라이브 링크입니다. 공개 링크나 유튜브 주소로 바꿔야 방문자가 볼 수 있습니다.
- 글꼴(Jua, Gothic A1)은 Google Fonts에서 불러옵니다.
